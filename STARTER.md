# Стартовая сборка Sfera

В этой версии доступны установка на пустую базу, вход, выход и главная страница для вошедшего пользователя. Для разработки используйте отдельный стенд и отдельную пустую базу.

## Запуск на SpaceWeb

1. Распакуйте содержимое public_html в корень учебного сайта, включая .htaccess. В панели выберите PHP 8.3, настройте HTTPS и создайте пустую базу MySQL.
2. Через файловый менеджер создайте файл sfera-install-token.txt рядом с public_html. Запишите в него уникальный случайный код длиной 32–128 символов из латинских букв, цифр, дефисов и подчёркиваний. Установщик сверяет введённый код с этим файлом.
3. Откройте /install.php по HTTPS, введите код и данные базы и создайте администратора. После установки удалите файл с кодом через файловый менеджер.
4. Откройте главную страницу, войдите новым администратором, затем проверьте выход.

## Локальный запуск

Требуются PHP 8.2 или новее с pdo_mysql, gd, fileinfo, mbstring и openssl и отдельная пустая MySQL или MariaDB. Передайте пароли через переменные окружения SFERA_DB_PASSWORD и SFERA_ADMIN_PASSWORD. Посмотрите аргументы через php tools/install.php --help. После установки запустите php -S 127.0.0.1:8080 -t public_html tools/router.php.
