## Проблемы и решения

- При первом добавлении ленты GitHub поместил три файла в корень репозитория. Закрыли исходный [PR №12](https://github.com/blareww/sfera/pull/12). В PR №13 проверили пути внутри public_html перед слиянием.
- На SpaceWeb PHP не распознавал HTTPS после установки сертификата. В конфигурации Apache добавили обработку признака HTTPS, который передаёт прокси SpaceWeb. Установка стартовой сборки на тестовом сайте прошла успешно. [Результаты проверки](spaceweb-check.md).

## Что показать

Открыть тестовый сайт, войти как администратор, открыть форму из пустой ленты, набрать «Тестовая запись» и показать предпросмотр. Сохранение публикаций в базу запланировано на следующий этап.
