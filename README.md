# Sfera

Учебная социальная сеть для небольших групп. MVP: два участника добавляют друг друга в друзья и обмениваются публикацией и комментарием.

## Архитектура

JavaScript и CSS отвечают за интерфейс. PHP API проверяет права доступа и сохраняет записи в MySQL. Вложения выдаются через media.php, закрытое хранилище расположено вне public_html. Стенд — виртуальный хостинг SpaceWeb с HTTPS.
